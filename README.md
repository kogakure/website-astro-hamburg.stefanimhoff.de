# hamburg.stefanimhoff.de

This is the source of my [walking journal](https://hamburg.stefanimhoff.de/), built
with [Astro](https://astro.build/), MDX content collections, and Tailwind CSS.

## Installation

```sh
pnpm install --frozen-lockfile
```

## Running the Website

```sh
pnpm start
```

Quality checks:

```sh
pnpm check
pnpm lint
pnpm format:check
pnpm test
pnpm build
pnpm test:e2e
```
